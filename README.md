# 📊 cubo-dashboard-ui

A modern analytics dashboard UI built using HTML & CSS Grid.

This project was created as part of Assignment 4 from Cohort 3.0 by Sheryians Coding School while practicing advanced CSS Grid layouts, floating dashboard cards, pseudo-elements, hover animations, and premium UI structuring concepts.

---

## 🚀 Features

- Modern Dashboard UI
- Advanced CSS Grid Layout
- Floating Analytics Cards
- Animated Hover Buttons
- Custom Progress Ring
- Pseudo-element Effects
- Interactive UI Components
- Typography Hierarchy
- Modern Pink Aesthetic

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Font Awesome
- Remix Icons
- Google Fonts

## 📚 Concepts Practiced

- display: grid
- grid-template-columns
- grid-template-rows
- grid-template-areas
- gap
- display: flex
- position: relative
- position: absolute
- ::before & ::after
- Hover Animations
- UI Structuring
- Alignment & Spacing
- Floating Card Composition
- Visual Hierarchy
